# The A — Telegram-бот

Бот [@BusinessManagerTheA_bot](https://t.me/BusinessManagerTheA_bot): меню тем,
фотоальбом с мероприятия, запись на консультацию и переписка клиента с менеджерами.

## Как это работает

**Стартовые экраны.** Обычный `/start` показывает общее приветствие. Ссылка
`t.me/BusinessManagerTheA_bot?start=ybc` (например, из QR-кода) показывает экран для
годовщины YBC Lisbon. Экранов может быть сколько угодно: они описаны в `start_screens`
в `content/texts.yaml`, вместе с набором и порядком кнопок. «Повернутись до тем» ведёт
на тот экран, с которого человек пришёл.

Кнопки:

- 📸 Фото с 4-й годовщины YBC Lisbon → текст + кнопка со ссылкой на альбом
- Темы (Банки, Налоги, Компания, Другое) → описание + «Написати менеджеру» / «Повернутись до тем»
- 📅 Запись на консультацию → имя → контакт → вопрос → заявка менеджерам

**Переписка с менеджерами.** Любое сообщение клиента бот пересылает в чат менеджеров
(с темой, которую клиент открыл последней). Чтобы ответить клиенту, менеджер нажимает
**«Ответить» (Reply)** на сообщение бота и пишет текст: бот доставит его клиенту.
Работают и фото, и файлы, и голосовые.

## Как поменять тексты

Все тексты, кнопки и ссылка на альбом лежат в [`content/texts.yaml`](content/texts.yaml).
Отредактируйте файл (можно прямо на GitHub), сохраните, и после деплоя бот заговорит по-новому.

- **Новая тема:** скопируйте блок в `topics:` и дайте ему новый `id` латиницей.
- **Порядок кнопок** задаётся списком `buttons` у каждого стартового экрана.
- **Новый QR-код / ссылка:** добавьте экран в `start_screens`, например `conf2027:`, и ссылка будет `t.me/BusinessManagerTheA_bot?start=conf2027`.
- **Форматирование:** `<b>жирный</b>`, `<i>курсив</i>`, `<a href="https://...">ссылка</a>`.

## Настройки (переменные окружения)

| Переменная | Что это |
|---|---|
| `BOT_TOKEN` | Токен из @BotFather |
| `MANAGERS_CHAT_ID` | Куда приходят сообщения и заявки: личный чат менеджера с ботом (или группа). Менеджер пишет боту `/myid`, бот присылает номер. Менеджер должен хотя бы раз нажать «Старт» в боте |

## Запуск локально

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements-dev.txt
cp .env.example .env   # и заполнить
python -m bot
```

Тесты: `pytest`

**Установка на сервер:** см. [deploy/README.md](deploy/README.md).

⚠️ Одновременно может работать только одна копия бота с этим токеном. Для экспериментов
лучше завести отдельного тестового бота в @BotFather.

## Структура

```
content/texts.yaml        все тексты
bot/__main__.py           запуск
bot/config.py             настройки из окружения
bot/content.py            загрузка и проверка texts.yaml
bot/keyboards.py          кнопки
bot/formatting.py         сообщения для менеджеров
bot/handlers/menu.py      /start, темы, фото
bot/handlers/consultation.py  запись на консультацию
bot/handlers/manager.py   переписка клиент ↔ менеджер
tests/                    автотесты
```
